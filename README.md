# Little Words 小小字卡

A tiny static picture dictionary in Taiwan Mandarin (Traditional Chinese): one page per word (`w/<id>/`) with the word spoken by the browser's built-in speech voice, a role-play card and toddler questions, plus `scan.html`, a continuous QR scanner that plays a word when its printed code is in view.

- No tracking, cookies, analytics or external scripts. Works offline after the first visit (service worker).
- QR decoding: browser BarcodeDetector when available, otherwise vendored [jsQR](https://github.com/cozmo/jsQR) 1.4.0 (Apache-2.0, see `assets/jsQR-LICENSE.txt`).
- Art: original vector icons.
- Generated by a build script; edit the source, not these files.
